# Dental Support — локальный прототип

## Запуск
1. Распакуйте архив в любую папку.
2. Откройте `index.html` двойным щелчком в Chrome, Edge или Яндекс Браузере.
3. Интернет не нужен для основной функциональности. Шрифт Inter загружается из Google Fonts, но при отсутствии интернета будет использован системный шрифт.

## Что работает
- Панель обращений: фильтры, поиск, статусы и приоритеты.
- Карточка обращения с описанием, клиентом, оборудованием и историей переписки.
- Добавление ответов в историю.
- Изменение статуса и приоритета, удаление обращения.
- Добавление клиентов и оборудования.
- Поиск по клиентам и оборудованию.
- Сводка по статусам и CSV-экспорт обращений.
- Адаптивная вёрстка для компьютера и телефона.
- Автосохранение в LocalStorage браузера.

## Важно
Это фронтенд-прототип. Данные хранятся только в текущем браузере на текущем компьютере. Между пользователями ничего не синхронизируется. Реальные email/Telegram/WhatsApp-уведомления, авторизация, сервер и общая база данных пока не подключены.
